# 🌍 Jelajah Keajaiban Alam — Metaverse Spasial 3D

Media pembelajaran metaverse 3D bergaya Roblox untuk **Kuttab Raudhah Nabawiyah (KRN)**, Bogor.
Siswa menjelajahi **8 ruang petualangan** berisi **25 keajaiban alam dunia**, menonton potongan film di layar 3D, menjawab kuis, membaca ayat tentang alam, lalu mengumpulkan **💎 poin** untuk membuka **Harta Karun** di Taman Keajaiban.

## 💎 Poin

| Kegiatan | Poin |
|---|---|
| Menonton potongan film (minimal 60%) | +5 dan 🔷 kristal |
| Kuis benar pada percobaan pertama | +10 |
| Kuis benar pada percobaan berikutnya | +5 |
| Membaca ayat Al-Qur'an tentang alam | +5 |
| **Membuka Harta Karun** | **perlu 250 💎** |

Setiap ruang yang kuisnya selesai memberi 🏅 **lencana**, yang menyalakan kristal pada pilar kuil di Taman Keajaiban.

## ✨ Fitur

- 8 portal ajaib dari pulau terapung **Taman Keajaiban** menuju ruang-ruang tematik: air terjun, salju, gurun, laut, gunung api di malam hari, dan sabana dengan hewan.
- 25 layar film 3D. Potongan film diputar langsung di layar, dan tombol ⛶ membesarkannya.
- 🦜 **Kiki si Pemandu** memberi petunjuk dengan suara.
- 📖 **Paspor Penjelajah** berisi stempel setiap keajaiban, 🗺️ **Peta** untuk teleportasi, dan 📸 **Mode Foto** yang bisa diunduh.
- Ayat-ayat tentang alam dengan teks Arab, terjemahan, dan murottal (Syaikh Mishary Alafasy).
- Upacara Harta Karun dengan kembang api, lalu 🏆 **Piagam Penjelajah** (PNG) yang bisa diunduh.
- Progres tersimpan otomatis di perangkat.
- Bisa dimainkan di laptop maupun HP/tablet.

## 🚀 Unggah ke GitHub Pages

1. Buat repository baru, misalnya `jelajah-alam`.
2. Klik **Add file → Upload files**, lalu seret `index.html`, `README.md`, dan **seluruh folder `klip/`** (26 file .mp4, total sekitar 56 MB; setiap file di bawah 100 MB).
3. Klik **Commit changes**.
4. Buka **Settings → Pages**, pilih *Deploy from a branch*, lalu pilih `main` dan `/ (root)`. Klik Save.
5. Tunggu 1–2 menit. Link akan muncul dalam format `https://<username>.github.io/jelajah-alam/`.

> ⚠️ Buka media ini melalui link GitHub Pages (atau server http). Jika `index.html` dibuka dengan klik ganda, film tidak tampil di layar 3D dan hanya terbuka di jendela besar. Folder `klip/` juga harus ikut diunggah, dengan nama dan letak yang sama.

## 🎬 Sumber Film & Hak Cipta

Potongan film diambil dari video **"25 Greatest Natural Wonders of the World – Travel Video"** (Touropia). Video ini memiliki hak cipta. Gunakan hanya untuk pembelajaran di kelas. Jika repository dibuat publik, sebaiknya minta izin pemilik video atau jadikan repository **private**.

Teks Al-Qur'an diambil dari quran-json, dengan font Amiri Quran. Murottal diputar dari everyayah.com, jadi fitur ini membutuhkan internet.
